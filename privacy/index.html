A Little Context

Privacy Policy

Last updated 12 November 2026

This policy covers this website and A Little Context tools, a private tool the A Little Context channel uses to keep track of its own videos on YouTube, TikTok and Instagram.

This website

This website doesn't use cookies, analytics or any tracking, and has no forms. Its host may keep standard server logs, such as IP addresses, for security and to keep the site running.

A Little Context tools

The tool isn't offered to the public. It is used only by the person who runs the channel, signed in to the channel's own accounts.

With that permission, it reads the channel's own profile (name, follower and video counts), its list of public posts (links, captions and posting times) and their statistics (such as views, likes, comments and shares). It reads nothing about anyone else. It doesn't post, edit or delete anything, and it doesn't read or send messages.

What it reads is stored only on the channel owner's computer, used only to check that each video went out correctly and to see how it is doing, and never shared, sold or used for advertising.

Removing access

The access can be withdrawn at any time in each platform's settings (for example TikTok's Manage app permissions, or Instagram's Apps and websites). The locally stored data is deleted when the tool stops being used.
